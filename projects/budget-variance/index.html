    How the analysis works

    Business problem

    Treasury revenue is budgeted by stream and reviewed every month. A single "we are 3% behind" figure is not enough for management: they need to know whether the shortfall is concentrated in one stream, whether it is a timing difference that is already reversing, and whether the full-year target is still reachable.

    Calculations and assumptions

    • Variance = Actual − Budget; Variance % = Variance ÷ Budget; Achievement = Actual ÷ Budget. For revenue, above budget is favourable.
    • Year-to-date figures accumulate January to the selected month (DATESYTD in the Power BI model).
    • Run-rate forecast = Actual YTD + remaining budget × YTD achievement rate. It assumes the rest of the year performs like the year so far.
    • SYP figures use one illustrative exchange rate, so variance % is the same in both currencies. With real rates the model would also separate an FX effect.

    Reading the results

    • The bridge attributes the total gap to each stream, so commentary can name the driver.
    • The cumulative variance bars show whether a gap is widening or being recovered.
    • The heat map separates a one-month miss from a persistent pattern.
    • The outlook turns the YTD position into a year-end landing and shows how reliable that forecast was at each point in the year.

    About this analysis

    Business question: Is revenue on track against budget, and if not, which stream and which months explain the gap?

    Approach: Monthly budget and actual figures for each currency were combined in Power Query into one fact table, linked to a date dimension (star schema). DAX measures calculate variance, variance %, achievement rate and year-to-date totals (DATESYTD), so every visual responds to the currency, month and stream filters.

    What this view adds: a variance bridge that splits the total gap by stream, a month × stream variance heat map, a run-rate full-year forecast with a forecast-accuracy track, and automatic findings that update with the filters.

    Practical use: this is the analysis behind monthly performance commentary for department heads: it identifies which stream to question, whether corrective action is already working, and whether the annual target should be re-forecast.
