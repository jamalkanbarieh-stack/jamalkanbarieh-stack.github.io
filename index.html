How this portfolio was built

Built in Power BI & Excel

Each project started as a Power BI report or Excel model. The web versions recalculate every figure from the original data and DAX logic, so they run in any browser without a Microsoft account.

Confidentiality first

Only public disclosures are used, and employer-internal material is excluded. Where a project mirrors internal work, as with the budget dashboard, the data is fictional and labelled as such.

Transparent methods

Every page states its data source, definitions and data-quality caveats, and includes an "About this analysis" section explaining the question, the approach and what was improved.
